# idsec_cmgr_connector (Resource)

Connector Management connector resource, manages connector management agent installation and removal on Connector Management and target machines.
<!-- BEGIN CUSTOM NOTES -->
<!-- END CUSTOM NOTES -->

## Example Usage

```terraform
resource "idsec_cmgr_connector" "example-linux" {
  connector_os      = "linux"
  connector_pool_id = var.pool_id
  target_machine    = var.target_machine
  username          = var.username
  private_key_path  = var.private_key_path
}

resource "idsec_cmgr_connector" "example-windows" {
  connector_os      = "windows"
  connector_pool_id = var.pool_id
  target_machine    = var.target_machine
  username          = var.username
  password          = var.password
  winrm_protocol    = "https"
}
```

## Schema

### Required

- `connector_os` (String) The operating system type of the target machine (linux, windows).
- `connector_pool_id` (String) The connector pool that the connector will be part of. If not provided, the connector is assigned to the default pool.
- `target_machine` (String) The target machine on which to install the connector.
- `username` (String) The username used to connect to the target machine.

### Optional

- `certificate_path` (String) Path to a custom CA certificate for WinRM HTTPS connections. Only applicable for Windows with HTTPS protocol.
- `installation_path` (String) The installation path for the connector on the target machine. Note: cannot be customized on Linux OS and error will be thrown.
- `password` (String, Sensitive) The password used to connect to the target machine.
- `private_key_contents` (String, Sensitive) The private key contents used to connect to the target machine via SSH.
- `private_key_path` (String) The private key file path used to connect to the target machine via SSH.
- `proxy_details` (Attributes) Optional proxy configuration. (see [below for nested schema](#nestedatt--proxy_details))
- `retry_count` (Number) The number of times to retry connecting to the target machine.
- `retry_delay` (Number) The number of seconds to wait between retries.
- `tenant_info` (Map of String) Optional tenant metadata (maximum 2 entries).
- `trust_certificate` (Boolean) When true, trusts any server certificate for WinRM HTTPS connections. Only applicable for Windows with HTTPS protocol.
- `version` (String) The connector version to install. If not provided, the default stable version according to the tenant configuration will be used.
- `winrm_protocol` (String) The protocol to use for WinRM connections (http, https).

### Read-Only

- `connector_id` (String) The ID of the connector to update.
