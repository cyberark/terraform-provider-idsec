# idsec_pcloud_user_group_member (Resource)

Privilege Cloud user group member resource, manages the membership of a Vault user in a Vault user group.
<!-- BEGIN CUSTOM NOTES -->
~> This resource is deprecated and will be removed in a future release. Vault-native user groups are no longer the recommended way to group principals.

-> This resource does not refresh its state and cannot be imported: a membership removed outside Terraform is not detected, and the resource has to be recreated to restore it.
<!-- END CUSTOM NOTES -->
