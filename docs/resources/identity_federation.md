# idsec_identity_federation (Resource)

The Identity service federation resource, which manages an external SAML 2.0 or OIDC identity provider.

<!-- END CUSTOM NOTES -->

## Example Usage

```terraform
# The identity provider values below are placeholders: replace them with your identity provider's.
# The server fetches oidc_metadata_url and saml_metadata_url when the federation is created and on
# every update, so they must be real URLs the tenant can reach, or the apply fails.

variable "okta_client_secret" {
  type      = string
  sensitive = true
}

variable "adfs_oauth_client_secret" {
  type      = string
  sensitive = true
}

# An external OIDC identity provider. Register oidc_redirect_url and oidc_initiate_login_url
# with the identity provider after the first apply.
resource "idsec_identity_federation" "okta" {
  federation_name = "Okta"
  federation_type = "OIDC"
  domains         = ["example.com"]
  # Your identity provider's discovery document, ending in /.well-known/openid-configuration.
  oidc_metadata_url  = "https://example.okta.com/.well-known/openid-configuration"
  oidc_client_id     = "0oa1b2c3d4e5f6g7h8i9"
  oidc_client_secret = var.okta_client_secret
  oidc_scopes        = ["openid", "profile", "email"]

  # Link federated users to Cloud Directory users by the email claim, create the missing ones, and keep
  # their display name in sync.
  map_users                    = "Required"
  map_user_attribute           = "email"
  map_user_directory_service   = "09B9A9B0-6CE8-465F-AB03-65766D33B05E"
  map_user_create_if_not_found = true
  attribute_mappings = [
    { target = "DisplayName", source = "name" },
  ]

  # Assertions of the groups claim, mapped in order to federated groups.
  group_mappings = [
    { attribute_value = "okta-admins", group_name = "Okta Admins" },
    { attribute_value = "okta-users", group_name = "Okta Users" },
  ]
}

output "okta_redirect_url" {
  value = idsec_identity_federation.okta.oidc_redirect_url
}

# An external SAML 2.0 identity provider read from its metadata URL. Register saml_sp_metadata_url,
# or saml_sp_acs_url and saml_sp_signing_certificate_url, with the identity provider.
resource "idsec_identity_federation" "adfs" {
  federation_name = "ADFS"
  federation_type = "SAML 2.0"
  domains         = ["corp.example.com"]
  # Your identity provider's SAML metadata document.
  saml_metadata_url   = "https://adfs.example.com/FederationMetadata/2007-06/FederationMetadata.xml"
  saml_sign_algorithm = "SHA256"

  # OAuth credentials that let users of this identity provider sign in with a password, through its
  # token URL.
  saml_oauth_client_id        = "identity-password-signin"
  saml_oauth_client_secret    = var.adfs_oauth_client_secret
  saml_oauth_access_token_url = "https://adfs.example.com/adfs/oauth2/token"
}

# A SAML 2.0 identity provider configured without metadata. saml_metadata_xml = file("metadata.xml")
# uploads a metadata document instead.
resource "idsec_identity_federation" "legacy" {
  federation_name  = "Legacy IdP"
  federation_type  = "SAML 2.0"
  domains          = ["legacy.example.com"]
  saml_sign_in_url = "https://idp.example.com/sso"
  saml_logout_url  = "https://idp.example.com/slo"
  # The identity provider's signing certificate, exported from it as PEM or base64, in a file next to
  # this configuration.
  saml_signing_certificate = file("idp-signing.pem")
}

output "adfs_acs_url" {
  value = idsec_identity_federation.adfs.saml_sp_acs_url
}
```

## Schema

### Required

- `federation_name` (String) The display name of the external identity provider.
- `federation_type` (String) The federation protocol.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `active` (Boolean) Whether the federation is active.
- `attribute_mappings` (Attributes List) Identity provider attributes copied onto Cloud Directory user attributes. Stored only when map_user_directory_service is the Cloud Directory and a sync or create option is on. (see [below for nested schema](#nestedatt--attribute_mappings))

<!-- BEGIN ATTR NOTE: attribute_mappings -->
~> Attribute mapping for external identity providers must be enabled on the tenant, which it is by default. When it is not, the server saves the federation but discards attribute_mappings without an error, so the apply fails with "Provider produced inconsistent result" and every later apply tries again. On such a tenant, leave attribute_mappings unset.
<!-- END ATTR NOTE: attribute_mappings -->
- `device_types` (Set of String) The device types routed to this identity provider. Empty means every device type. A partial selection requires map_users Required.
- `domains` (Set of String) The federated domains routed to this identity provider.

<!-- BEGIN ATTR NOTE: domains -->
-> With routing rules enabled on the tenant, the server rejects a federation that has no routing rule configured. Domains are the only routing rule this resource manages today, so set at least one.
<!-- END ATTR NOTE: domains -->
- `group_mappings` (Attributes List) The identity provider group assertions mapped to federated groups, in order. (see [below for nested schema](#nestedatt--group_mappings))
- `map_user_allow_other_federations` (Boolean) Whether the federated user may map to a user that belongs to another federation.
- `map_user_attribute` (String) The identity provider attribute used to find the directory user.
- `map_user_by` (String) The directory user attribute matched against map_user_attribute.
- `map_user_create_if_not_found` (Boolean) Whether a Cloud Directory user is created when none is found. Requires map_users Required.
- `map_user_directory_service` (String) The directory service UUID searched for the user. Empty means any directory service.
- `map_user_sync_with_cloud_user` (Boolean) Whether the directory user is updated from the identity provider attributes.
- `map_user_sync_with_federated_user` (Boolean) Whether the federated user is updated from the identity provider attributes.
- `map_user_uses_groups` (Boolean) Whether the mapped user also receives the federated group memberships.
- `map_users` (String) Whether federated users are linked to existing directory users.
- `oidc_client_id` (String) The client ID registered at the OIDC identity provider. Required for OIDC.
- `oidc_client_secret` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The client secret registered at the OIDC identity provider. Required for OIDC. Write-only: this value is never stored in Terraform state or plan. It is sent to the API on create, and on update whenever it changes; rotation is detected automatically via the computed `oidc_client_secret_write_only_hash` attribute, so no manual trigger needs to be bumped. Requires Terraform 1.11 or later.
- `oidc_grant_type` (String) The OIDC grant type. Defaults to AuthorizationCode for OIDC.
- `oidc_metadata_url` (String) The full OIDC discovery document URL, ending in /.well-known/openid-configuration. Required for OIDC.
- `oidc_pkce_enabled` (Boolean) Whether PKCE is used. Defaults to true for OIDC.
- `oidc_post_logout_redirect_uri` (String) The post logout redirect URI.
- `oidc_scopes` (Set of String) The scopes requested from the OIDC identity provider.
- `saml_logout_url` (String) The SAML identity provider logout URL. Read from the metadata when it is supplied.
- `saml_metadata_url` (String) The SAML identity provider metadata URL. The server fetches the metadata on every create and update.

<!-- BEGIN ATTR NOTE: saml_metadata_url -->
-> The server fetches the metadata again on every create and update, so the URL must stay reachable from the tenant, and an apply picks up a rotated identity provider certificate.
<!-- END ATTR NOTE: saml_metadata_url -->
- `saml_metadata_xml` (String, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The SAML identity provider metadata document, uploaded instead of fetching it from saml_metadata_url. Write-only: this value is never stored in Terraform state or plan. It is sent to the API on create, and on update whenever it changes; rotation is detected automatically via the computed `saml_metadata_xml_write_only_hash` attribute, so no manual trigger needs to be bumped. Requires Terraform 1.11 or later.

<!-- BEGIN ATTR NOTE: saml_metadata_xml -->
-> A federation created from a metadata document reads back like one configured manually: saml_sign_in_url, saml_logout_url and the certificate attributes hold the values read from it. The document is only sent again when it changes.
<!-- END ATTR NOTE: saml_metadata_xml -->
- `saml_oauth_access_token_url` (String) The identity provider's OAuth token URL, used for password sign-in. Must be an https URL.
- `saml_oauth_client_id` (String) The OAuth client ID the tenant uses to sign the identity provider's users in with a password, through saml_oauth_access_token_url.
- `saml_oauth_client_secret` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The OAuth client secret for saml_oauth_client_id. The server keeps the stored secret when none is sent. Write-only: this value is never stored in Terraform state or plan. It is sent to the API on create, and on update whenever it changes; rotation is detected automatically via the computed `saml_oauth_client_secret_write_only_hash` attribute, so no manual trigger needs to be bumped. Requires Terraform 1.11 or later.
- `saml_sign_algorithm` (String) The algorithm the SAML authentication request is signed with.
- `saml_sign_in_url` (String) The SAML identity provider sign-in URL. Read from the metadata when it is supplied.
- `saml_signing_certificate` (String, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The SAML identity provider signing certificate, PEM or base64 encoded, for a federation configured without metadata. Write-only: this value is never stored in Terraform state or plan. It is sent to the API on create, and on update whenever it changes; rotation is detected automatically via the computed `saml_signing_certificate_write_only_hash` attribute, so no manual trigger needs to be bumped. Requires Terraform 1.11 or later.

<!-- BEGIN ATTR NOTE: saml_signing_certificate -->
~> Two SAML federations on a tenant cannot share an identity provider signing certificate, whichever way it was supplied.
<!-- END ATTR NOTE: saml_signing_certificate -->
- `saml_url_redirect_enabled` (Boolean) Whether users are redirected to a URL that matches saml_url_redirect_pattern after SAML sign-in.
- `saml_url_redirect_pattern` (String) The https URL pattern, which may contain *, that redirection after SAML sign-in is allowed to.
- `user_agents` (Set of String) The client types routed to this identity provider.
