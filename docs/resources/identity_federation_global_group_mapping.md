# idsec_identity_federation_global_group_mapping (Resource)

The Identity service federation global group mapping resource, which maps a group attribute value from any external identity provider to an Identity group.

## Example Usage

```terraform
# Maps the "admins" group assertion of every federation to the "Federated Admins" group.

  attribute_value = "admins"
  group_name      = "Federated Admins"
}
```
