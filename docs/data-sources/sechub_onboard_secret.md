# idsec_sechub_onboard_secret (Data Source)

Secrets Hub secret data source, finds a single discovered secret by its exact name and secret store ID, to be used as input for secret onboarding.
<!-- BEGIN CUSTOM NOTES -->
-> The secret must already have been discovered by a Secrets Hub scan of the secret store. The lookup fails if no secret exactly matches `name` in the store, if more than one secret matches, or if the secret is not a candidate for onboarding.
<!-- END CUSTOM NOTES -->

## Example Usage

```terraform
data "idsec_sechub_onboard_secret" "example_secret" {
  name     = var.secret_name
  store_id = var.store_id
}
```

- `name` (String) Name of the secret as defined in the secret store

### Read-Only

- `discovered_at` (String) The date and time that the secret was discovered by the Secrets Hub scan.
- `id` (String) The unique identifier of the secret in Secrets Hub (internal).

- `store_name` (String) Name of the secret store
- `synced_by_cyberark` (Boolean) Indicates whether the secret has been synced by Idira. If not set, the status is unknown.
- `vendor_data` (Attributes) Data related to the secret as defined in the cloud platform. (see [below for nested schema](#nestedatt--vendor_data))
- `vendor_sub_type` (String) The subtype of the secret store where the secret was discovered (ASM, AKV, GSM)
- `vendor_type` (String) The vendor type of the store where the secret was found (AWS, AZURE, GCP)
